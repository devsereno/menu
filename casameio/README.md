# CasaMeio

PWA da conta de casa (metade + pessoal).

## Local
```
npm install
npm run dev
```

## GitHub + Cloudflare
O Pages já está em `casameio.pages.dev` com:
- preset React (Vite)
- `npm run build`
- pasta `dist`

Depois do push na `main`, o deploy sobe sozinho.

Tema claro/escuro: botão no canto e também em Família.
